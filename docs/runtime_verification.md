# Проверка итогового варианта hw01

Итоговая команда — `./scripts/verify.sh --full` из опубликованной ветки hw1. Финальный CI использует ту же команду на пустых томах. Ссылку и исходные числа этого прогона нужно зафиксировать после завершения; JSON чекера не изменяется.

Успешный автоматический результат: все десять секций, **139/139 и 21/21 автоматических баллов**, без исключений. Ещё 4 балла выставляются вручную за карту склейки, ADR, журнал и кворумный etcd; скрипт их не начисляет.
