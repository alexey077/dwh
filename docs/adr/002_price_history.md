# 2. История и область действия цены

## Задача

Цена меняется во времени и может относиться к сети, региону или аптеке. Требуется восстановить цену на дату продажи.

## Решение

Выбрал отдельную таблицу версий с интервалом `[valid_from, valid_to)`. Пересечения запрещает `EXCLUDE USING gist` с `btree_gist`. `is_current` вычисляется из `valid_to IS NULL`, поэтому чтение мастера и реплики даёт одинаковый результат.

## Почему не другой вариант

Вариант «обновлять единственную текущую цену» отверг: пропадут исходные значения для исторических продаж. Вариант с проверкой пересечений только в Python отверг: два клиента могут записать конфликтующие интервалы.

Область выбирается в порядке аптека → регион → сеть. Функция учитывает дату и границы интервала. Опубликованную сумму версии менять нельзя: старый интервал закрывается, новая цена получает новый BK.

## Последствия

запрос цены сложнее, интервалы нужно закрывать согласованно. Текущая техническая версия означает открытый интервал; действительность на конкретную дату определяется отдельно.
