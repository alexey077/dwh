# Требования и подтверждение результата

Здесь указано, чем проверяется каждый блок. Статус выполнения и фактический вывод проверок находятся в `docs/progress.md`.

| Требование | Реализация | Проверка |
|---|---|---|
| 4 отдельные базы, автоматическая структура | `migrations/`, `scripts/`, `docker-compose.yml` | Запуск с пустыми томами, секция `contract` |
| 14 представлений `contract` | Миграции четырёх сервисов | `contract`, `keys` неизменённого чекера |
| Объёмы и связность | `scripts/seed.sh` и генератор | `volume`, C01–C23, X01–X10 |
| Идемпотентность и дельта | Учёт порций генератора | Повторная загрузка; рост документов после новой порции |
| I1–I12, P1–P2 | Ограничения и `tests/invariants/` | `inv`, реальные SQLSTATE |
| Физические реплики и слоты | `infra/patroni/` | `repl`, WAL receiver, отпечатки 14 представлений |
| HAProxy и PgBouncer | `infra/haproxy/`, `infra/pgbouncer/` | `ha`, подключение через пул, разделение чтения и записи |
| CDC | `wal_level=logical`, публикации, ключи | `cdc` |
| Четыре ER-диаграммы | `docs/erd/` | Сверка с фактическими миграциями |
| Не менее 5 ADR | `docs/adr/` | Контекст, варианты, выбор, отвергнутый вариант, последствия |
| Карта склейки | `docs/dwh_mapping.md` | Все разделы шаблона и минимум 3 сложности интеграции |
| Реалистичные данные | Распределения генератора | Все 5 метрик секции `realism` |
| Эксперименты Э1–Э7 и кворум etcd | Скрипты и журнал | Реальный запуск, команды, сырой вывод, измерения |
| Ветка и состав сдачи | `hw1`, корневой манифест и README | Чистый клон опубликованного коммита |
| Приватность и доступ `mgcrp` | Настройки GitHub | Проверка состояния репозитория; не подменять документацией |
